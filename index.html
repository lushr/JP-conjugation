ない — negative

う-verbs: final sound → あ-row + ない. う → わない.

かく → かかない　 のむ → のまない　 かう → かわない

る-verbs: drop る + ない.　たべる → たべない

た — short past

う・つ・る → った　かう → かった

む・ぶ・ぬ → んだ　のむ → のんだ

く → いた　かく → かいた

ぐ → いだ　およぐ → およいだ

す → した　はなす → はなした

る-verbs: drop る + た.　たべる → たべた

なかった — negative past

Make the ない form, then change ない → なかった.

のむ → のまない → のまなかった

て — て-form

う・つ・る → って　かう → かって

む・ぶ・ぬ → んで　のむ → のんで

く → いて　かく → かいて

ぐ → いで　およぐ → およいで

す → して　はなす → はなして

る-verbs: drop る + て.　たべる → たべて

たり — listing actions/states

Make the た form + り.

のむ → のんだ → のんだり　 たべる → たべた → たべたり

う-verbs

The ending changes according to its final kana. Watch る-verbs that are actually う-verbs: かえる → かえらない, はいる → はいらない.

る-verbs

Usually drop る before the ending: たべる → たべない / たべた / たべて.

い-adjectives

ない: 〜くない　 た: 〜かった　 なかった: 〜くなかった

て: 〜くて　 たり: 〜かったり

たかい → たかくない / たかかった / たかくなかった / たかくて / たかかったり

な-adjectives

ない: 〜じゃない　 た: 〜だった　 なかった: 〜じゃなかった

て: 〜で　 たり: 〜だったり

しずか → しずかじゃない / しずかだった / しずかじゃなかった / しずかで / しずかだったり

Irregular

する: しない / した / しなかった / して / したり

くる: こない / きた / こなかった / きて / きたり

いく: いかない / いった / いかなかった / いって / いったり

ある: ない / あった / なかった / あって / あったり

いい: よくない / よかった / よくなかった / よくて / よかったり
