ない — negative

う-verbs

Change the final sound to the あ-row + ない

かく → かかない
のむ → のまない
かう → かわない

る-verbs

Drop る + ない

たべる → たべない

い-adjectives

Change い → くない

たかい → たかくない

な-adjectives

Add じゃない

しずか → しずかじゃない

た — short past

う-verbs

う・つ・る → った
かう → かった

む・ぶ・ぬ → んだ
のむ → のんだ

く → いた
かく → かいた

ぐ → いだ
およぐ → およいだ

す → した
はなす → はなした

る-verbs

Drop る + た

たべる → たべた

い-adjectives

Change い → かった

たかい → たかかった

な-adjectives

Add だった

しずか → しずかだった

なかった — negative past

う-verbs

Make the ない form, then change ない → なかった

のむ → のまない → のまなかった

る-verbs

Make the ない form, then change ない → なかった

たべる → たべない → たべなかった

い-adjectives

Change い → くなかった

たかい → たかくなかった

な-adjectives

Add じゃなかった

しずか → しずかじゃなかった

て — て-form

う-verbs

う・つ・る → って

む・ぶ・ぬ → んで

く → いて
かく → かいて

およぐ → およいで

る-verbs

Drop る + て

い-adjectives

Change い → くて

たかい → たかくて

な-adjectives

Add で

しずか → しずかで

たり — listing actions / states

う-verbs

Make the た form + り

のむ → のんだ → のんだり

る-verbs

Make the た form + り

たべる → たべた → たべたり

い-adjectives

Change い → かったり

たかい → たかかったり

な-adjectives

Add だったり

しずか → しずかだったり

う-verbs

The ending changes according to the final kana.

Some verbs ending in る are still う-verbs:

かえる → かえらない
はいる → はいらない

る-verbs

Drop る before adding the new ending.

たべる → たべない
たべる → たべた
たべる → たべて
